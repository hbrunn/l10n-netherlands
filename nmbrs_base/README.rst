Configuration
=============

To configure this module, you need to:

1. Go to ``General Settings``
2. Scroll down to ``Nmbrs Integration``
3. Fill in your credentials
4. Press ``Fetch Master Data``
5. When you're convinced the integration works the way it should,
   disable ``Use sandbox``

Usage
=====

To use this module, you need to install at least one module that
actually does something.
